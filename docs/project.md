What changed between specification revisions. Every revision lives in `requirements/fsd/`, one file per

## V1 → V2 · received 2026-11-17

- **New requirements:** V2 specifies the Book — the template, `book init` and `book verify`, the stack and
  host packs, the guard and checks as data in `factory.toml`, the two Book agents.
- **What did not change:** nothing carries over — V1 was the setup placeholder ("Describe what the
  product must do here").
- **What this lands on:** every part of the repository.
- **How this comparison was produced:** read side by side by the person building v1.0.0.
