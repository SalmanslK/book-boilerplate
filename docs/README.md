# The Book — start here

The documents that say what the Book Boilerplate is, how it is built, and where the work has got to.
Which document owns which topic is the table in [`CLAUDE.md`](../CLAUDE.md#where-knowledge-lives); this
page is the reading order.

| Read | To learn |
|---|---|
| [`system-overview.md`](system-overview.md) | What the boilerplate is, its words, who uses it, and the main flows |
| [`architecture.md`](architecture.md) | How it is built, and why each rule exists |
| [`project.md`](project.md) | What is built, what is next, and what the latest specification changed |
| [`plans/`](plans/) | One feature's design and its tasks |
| [`open-questions.md`](open-questions.md) | What the requirements leave open, and the rules decided for it |
| [`defects.md`](defects.md) | What is wrong, and what happened to it |
| [`Audit/`](Audit/) | Specification ↔ plan ↔ code ↔ test traceability, written by `/book:fact-check` |
| [`archive/`](archive/) | Closed history — never a current rule |

How to write any of them: [`CLAUDE.md`](CLAUDE.md) in this folder.
